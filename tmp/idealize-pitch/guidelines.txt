App Prototype Submission Requirements
You must submit a working version of your application prior to the pitch. Ensure all links are publicly
accessible and require no special permissions to view.
For Web Applications:
Submit a Live Hosted Link (e.g., via Vercel, Netlify, Firebase, AWS, etc.).
Ensure the site is fully deployed and responsive.
For Mobile Applications (Android):
Submit a functional .apk file.
Upload the .apk to Google drive and submit the shared link. Ensure the access is set to "Anyone with
the link".
For Mobile Applications (iOS):
Submit a TestFlight link or a comprehensive screen-recording demo if live deployment is restricted.
